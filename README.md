# 稿序

稿序（Gaoxu）是本地运行的文章分发管理台。你可以从 Easy WeChat 固定下载目录选稿，保留原文、署名、配图和文末链接。审核通过后，系统按平台轮流分给所选模拟账号，根据北京时间、账号每日上限和发布间隔排期。

批量转载时，知乎与今日头条可分别使用公众号直链、已核对的 HTTPS 短链，或省略附加的文末链接。审核页可查看对应的平台稿。

选稿时可查看每篇文章在哪些平台已有任务。勾选平台后，点「补选缺排文章」可按原文链接筛选，再为缺少的平台补排。

手头有公众号链接时，可在「批量转载 → 按公众号原文链接选稿」中每行粘贴一条，点击「匹配下载目录」。同一篇有多份下载时可手选目录，然后一次加入选稿，沿用原有的审核、分稿和排期流程。

一次最多选择 100 篇。提交后可关闭页面，返回批次查看每篇资料的读取进度、预览稿件，或单独重试读取失败的文章。

可为平台与账号单独设置时段、间隔和日上限。在「转载审核与分稿」填写新任务最早排期，可预览并锁定每篇稿的账号和北京时间。排期日历按月展示任务，点击日期可查看分稿明细。

在管理台可按文章标题、平台、账号和日期跨批次查询，核对计划时间、实际交付时间和模拟回执。后台调度器独立运行，支持在服务重启后恢复未完成任务。

## 在 Windows 上运行

双击项目根目录的 **启动稿序.bat**。首次在新电脑使用需要 uv、Node.js（含 npm）和网络。启动器会准备项目自己的 Python 3.12 环境、安装管理台依赖并构建网页。以后双击同一个文件即可打开管理台。服务与调度器就绪后才会打开浏览器。

拉取 GitHub 更新后，再双击 **启动稿序.bat** 即可启用本地新版。若后台正在处理文章，启动窗口会等当前工作完成再切换版本，后续排期仍从原数据库继续。

需要 Windows 重启后继续执行排期时，保持管理台运行，双击 **配置稿序自启动.bat**。选择登录后或开机时恢复，核对窗口显示的任务库，再输入 Y。可在「调度器状态 → 检查本机自启动配置」查看绑定路径。

首次选稿时打开「批量转载 → 保存目录设置」，粘贴 Easy WeChat 的保存路径并点击「保存并读取目录」。换电脑时请分别迁移文章目录和任务数据库、模拟回执。仍在等待读取的旧批次需要原路径。迁移与启动说明见[运行手册](DISTRIBUTION.md#启动运行与恢复)。[打开本机管理台](http://127.0.0.1:5419/#/distribution)

## 从选稿到交付

1. 打开「批量转载」，从保存目录选文章，勾选知乎和今日头条的模拟账号。
2. 在「转载审核与分稿」预览各平台的正文、配图和文末链接。核对分配的账号和北京时间，再确认排期。
3. 在管理台按标题、账号或日期查询任务。点开一条任务可查看冻结版本和模拟回执。

**单篇知乎草稿验证**需要单独启动。取得正文和配图用于知乎草稿的授权后，双击 **启动知乎草稿助手.bat**，选择 **3**。在管理台「知乎草稿账号」核对接收账号，打开要验证的冻结稿，记录授权并确认保存。助手只处理此次选定的一篇。仅核对账号可选 1，已有已确认任务编号可选 2。知乎编辑器里的实际排版、配图和链接仍待真实账号验证。[草稿操作说明](DISTRIBUTION.md#知乎草稿箱)
