# 稿序

稿序（Gaoxu）是本地运行的文章分发管理台。你可以从 Easy WeChat 固定下载目录选稿，保留原文、署名、配图和文末链接。审核通过后，系统按平台轮流分给所选模拟账号，根据北京时间、账号每日上限和发布间隔排期。

批量转载时，知乎与今日头条可分别使用公众号直链、已核对的 HTTPS 短链，或省略附加的文末链接。审核页可查看对应的平台稿。

选稿时可查看每篇文章在哪些平台已有任务。勾选平台后，点「补选缺排文章」可按原文链接筛选，再为缺少的平台补排。

一次最多选择 100 篇。提交后可关闭页面，返回批次查看每篇资料的读取进度、预览稿件，或单独重试读取失败的文章。

可为平台与账号单独设置时段、间隔和日上限，在排期日历按月查看任务，并点击日期查看分稿明细。

在管理台可按文章标题、平台、账号和日期跨批次查询，核对计划时间、实际交付时间和模拟回执。后台调度器独立运行，支持在服务重启后恢复未完成任务。

## 在 Windows 上运行

双击项目根目录的 **启动稿序.bat**。首次在新电脑使用需要 uv、Node.js（含 npm）和网络。启动器会准备项目自己的 Python 3.12 环境、安装管理台依赖并构建网页。以后双击同一个文件即可打开管理台。服务与调度器就绪后才会打开浏览器。

默认读取 Easy WeChat 的固定下载目录。换电脑时请分别迁移文章目录和 `data/distribution` 下的任务数据及模拟回执。更换保存路径、更新前端和只读启动检查的命令见[运行手册](DISTRIBUTION.md#启动运行与恢复)。[打开本机管理台](http://127.0.0.1:5419/#/distribution)

可选的知乎草稿桥支持将多个分稿别名分别绑定到知乎账号 ID。审核时已绑定的稿件会锁定接收账号，操作员在对应浏览器账号下确认后才会发送到草稿箱。该功能等待真实账号验收。

转载审核默认仅用于本地试稿。取得正文及配图的知乎草稿使用授权后，可在冻结稿详情记录对应账号和版本的授权，再单独确认保存。
